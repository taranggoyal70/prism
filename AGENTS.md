# PRISM agent guidance

Follow the repository-level instructions inherited from the workspace. Keep PRISM as one Vercel-native Next.js application with a small, typed integration boundary.

## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

PRISM uses a single-context domain layout. See `docs/agents/domain.md`.
